                         QUICK START GUIDE
================================================================================

OPTION 1: Direct API Integration (5 minutes)
--------------------------------------------
1. Clone repository
2. Install dependencies: pip install anthropic openai
3. Set API key: export ANTHROPIC_API_KEY="sk-ant-..."
4. Load system prompt from IDENTITY.md + JAILBREAK.md + GODMODE.md
5. Make requests (zero refusals)

OPTION 2: Telegram Bot (10 minutes)
------------------------------------
1. Create bot via @BotFather
2. Configure config.yaml with tokens
3. Run: python telegram_bot.py
4. Message bot (unrestricted responses)

OPTION 3: Hermes Agent (5 minutes)
-----------------------------------
1. Copy files to ~/.hermes/profiles/your_profile/
2. Append JAILBREAK.md + GODMODE.md to instructions.md
3. Copy IDENTITY.md to identity.md
4. Restart Hermes
5. Full zero-refusal capability active
